Install

Tell your AI assistant:

Install Autonomo in my project. Read https://github.com/sebringj/autonomo/blob/main/QUICKSTART.md

Your AI handles the rest — installing packages, configuring MCP, and adding the bridge to your app. Works with Copilot, Claude Code, Cursor, and Windsurf.

Or install manually (npm) 
npm install github:sebringj/autonomo#packages/@autonomo/react
MCP config (.vscode/mcp.json) 
{
  "servers": {
    "autonomo": {
      "command": "autonomo-mcp",
      "args": ["--multi"]
    }
  }
}

For Cursor or Windsurf, add the same config to your MCP settings.
